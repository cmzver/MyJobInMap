# Roadmap

ссылаются на [технический аудит](docs/TECHNICAL_AUDIT_2026-10-25.md).

Обновлено: 29 октября 2026.

## Сейчас — стабилизация после аудита

- **Идемпотентность статуса/даты — атомарно.** Ключ комментария пишется в одной
  транзакции с операцией; для статуса и плановой даты сервис коммитит сам, и ключ
  сохраняется следом — узкое окно повторного выполнения при падении между ними (A12).
- **Остальные sync-маршруты вне event loop.** Перевести оставшиеся синхронные
  SQLAlchemy-обработчики в threadpool / `def`-обработчики (A11).
- **Сессия портала.** Хранить refresh, один общий refresh на параллельные 401 и
  повтор запроса; не обрезать пробелы в пароле (аудит, рекомендация 3).

## Затем — CI и тесты

- Portal CI: добавить `npm run lint` и `npm test` (сейчас только tsc + build).
- Android workflow: JVM-тесты и compile/lint.
- Проверка дрейфа OpenAPI-типов (портал и Android) в CI.
- Тесты запуска и миграций: lifespan, `python -m app.migrate` на чистой БД и
  upgrade со старых схем на PostgreSQL.
- Lock-файл транзитивных Python-зависимостей и регулярная проверка advisories.
- Пользовательские сценарии портала: login/refresh, смена организации,
  создание/редактирование заявки.

## Позже — архитектура и данные

- **Деньги.** `payment_amount` из Float в Numeric / minor units с миграцией и
  согласованием API и Kotlin-модели.
- **Индексы.** EXPLAIN/p95 по tenant/status/assignee/planned_date, составные
  индексы (в т.ч. под `updated_at` — инкрементальная синхронизация уже работает
  через `updated_since` + `/api/tasks/ids`).
- **Transactional outbox** для гарантированной доставки push/событий (A14).
- **Realtime перед масштабированием.** Redis Pub/Sub для WebSocket, общий
  rate limiter и один владелец scheduler — до увеличения числа API-процессов.
- **Android: domain → data.** Интерфейс `TasksRepository` в domain вместо
  зависимости use case от конкретного репозитория.
- **Группы пользователей.** Android-гейтинг по `base_access` вместо доменного
  `UserRole`; возможный отказ от глобальных dispatcher/worker.
- **Адреса.** `parse_address` не разбирает формат «Невская, д. 9, г.п. Новоселье»;
  бэкафилл `tasks.address_id` для старых заявок.
- **Тесты на SQLite.** Сервер и тесты всё ещё поддерживают SQLite (in-memory
  в тестах по умолчанию). Решить: оставить как быстрый режим тестов или
  перевести тесты целиком на PostgreSQL и убрать SQLite-ветки из кода.

## Эксплуатация (нужен доступ к серверу)

- **Домофоны.** Отдельный WireGuard-пир для прода и ротация ключей, сейчас пир
  общий с ноутбуком. Android-UI управления дверью (модели уже есть).
- **IP-guard.** Проверить на проде `TRUST_PROXY_HEADERS=true` и что SNI-роутер
  передаёт реальный IP клиента в Caddy — иначе защита видит один IP на всех.
- **Восстановление из бэкапа** как проверяемый сценарий, лимиты ресурсов
  контейнеров.
