# ADR-0004 — Права мастера

## Status

Accepted (2026-11-08, решения владельца продукта)

## Context

Мастер (базовый доступ `worker`, в том числе кастомные группы с этим уровнем)
мог менять карточку объекта, включая IP и порт сетевой панели домофона — команда
«открыть дверь» ушла бы на другой адрес; мог перевыпустить ссылку заявителю на
статус (сбрасывая его Telegram-подписки); получал по WebSocket названия чужих
заявок.

## Decision

- Карточку объекта (системы, оборудование, панели, документы, контакты,
  деактивация адреса) меняют только диспетчер и администратор
  (`get_current_dispatcher_or_admin`, учитывает `base_access`). Мастер — чтение,
  открытие двери, статус замка, снимок.
- `POST /tasks/{id}/status-link?renew=true` — только диспетчер и админ; получить
  текущую ссылку может и мастер.
- События заявок: диспетчер/админ — все заявки организации; мастер — только
  назначенные ему (при переназначении — прежний и новый исполнитель).
- Ссылка клиенту на подписание акта (`/api/acts/{id}/public-link`, каждый раз
  новая) — остаётся доступной мастеру: он выпускает её на месте.

## Consequences

Клиенты прячут соответствующие кнопки (портал — `canManageObjectData`, Android —
кнопок правки карточки объекта нет). Тесты: `test_address_card_permissions.py`,
`test_task_event_audience.py`.
