# ADR-0003 — Геокодирование: сначала DaData

## Status

Accepted (2026-11-08)

## Context

Заявки без дома в базе получали координаты от Nominatim (OSM). С IP прода
Nominatim отвечает 429 на любой запрос (блок по IP, User-Agent не влияет) —
новые заявки оставались в (0,0) и пропадали с карты. Кроме того, OSM находил
одноимённые места в других регионах («Новоселье» в Ярославской области вместо
Ленинградской), а подсказки DaData дополняют набранное и на «Центральная, 20»
первой возвращают «д 2».

## Decision

`GeocodingService.geocode()`:

1. точка дома из DaData (`qc_geo` 0/1, номер дома совпадает) — сразу;
2. иначе Nominatim;
3. если OSM молчит или его точка дальше 30 км от точки справочника (регионы
   работы в приоритете `ADDRESS_SUGGEST_BOOST_KLADR`) — центр улицы из DaData
   (`qc_geo` 2); хуже улицы не используем.

Район и код дома ФИАС адреса (`addresses.district`, `fias_id`) берутся из того же
запроса; код ФИАС — только у того самого дома.

## Consequences

- Работает без Nominatim; точность для домов без точки — уровень улицы.
- Бесплатный тариф DaData — 10 000 запросов в сутки; ответы кэшируются (24 ч).
- Разовые скрипты для старых данных: `scripts/link_tasks_to_addresses.py
  [--geocode]`, `scripts/backfill_address_district.py`.
